# IKS Codebase Reference

> Comprehensive technical reference for the भारतीय ज्ञानप्रणाली व वारसा / Elements of Indian Knowledge Systems website.
> GitHub: https://github.com/vivek-sovani/IKS · Live: https://vivek-sovani.github.io/IKS

---

## Project at a Glance

A bilingual (Marathi + English) educational website presenting 60 articles (53 chapters + 4 appendices + 3 extras) from the book *Elements of Indian Knowledge Systems*. The Marathi translation is by Vivek Sovani.

**Technology stack:** Vanilla HTML/CSS/JS — no framework, no bundler. Static files served via GitHub Pages.

**Key invariants:**
- Every visible element has both `data-lang="mr"` and `data-lang="en"` versions
- Articles are authored in `content.json` and generated with `node build.js`
- Never open HTML files via `file://` — always use a local server

## Article Registry — site.json

`site.json` is the single source of truth for sections and article metadata.

### Structure

```json
{
  "site": { "titleMr": "...", "titleEn": "...", "baseUrl": "..." },
  "sections": [
    { "id": "c0", "numMr": "०", "numEn": "0", "nameMr": "...", "nameEn": "...", "articles": ["01"...] }
  ],
  "articles": {
    "01": { "titleMr": "आनंद", "titleEn": "Ananda — The Nature of Joy", "section": "c0", "status": "published" }
  }
}
```

## Build Pipeline — build.js

`build.js` is a Node.js script (no dependencies). It reads `articles/NN/content.json` and generates `articles/NN/index.html`.

```bash
node build.js 05        # build single article
node build.js all       # rebuild every article that has content.json
```

### What build.js does

1. Reads `articles/NN/content.json` and `site.json`
2. Looks up the article's section (`c0`–`c4`) for breadcrumb and badge text
3. Determines badge type: "अध्याय N" for chapters, "परिशिष्ट N" for appendices (`section === 'c4'` or `appendix: true`)
4. Builds a poster image panel that auto-hides via `onerror` if `img/adhyayNN-poster.jpg` doesn't exist
5. Generates all content blocks (sections, term boxes, infographics, etc.)
6. Emits a full self-contained HTML page with inline scripts for sidebar fetch and swipe/zoom init

### Helper functions in build.js

| Function | Purpose |
|----------|---------|
| `toDevanagari(n)` | Converts Arabic numeral to Devanagari (e.g. `5` → `५`) |
| `md(text)` | Converts `**bold**` markdown to `<strong>bold</strong>` |
| `biP(mr, en)` | Emits a bilingual `<p data-lang="mr">` / `<p data-lang="en" style="display:none;">` pair |
| `renderSection(b)` | Renders a `section` block with optional `insight-block` |
| `renderTermBox(b)` | Renders a Sanskrit term definition box |
| `renderConcepts(b)` | Renders the key concepts card grid |
| `renderCuriosity(b)` | Renders a curiosity/जिज्ञासा box |
| `renderActivity(b)` | Renders an activity/कृती ordered list |
| `renderPhase2(b)` | Renders the "Advanced Reading — Coming Soon" teaser |
| `renderSlides(b, id)` | Renders the PDF slide viewer HTML skeleton |
| `renderInfographic(b)` | Dispatches to `svgFlow`, `svgWheel`, or `svgBars` |
| `svgFlow(inf)` | Generates a left-to-right step flow SVG |
| `svgWheel(inf)` | Generates a central concept + 4 quadrant SVG |
| `svgBars(inf)` | Generates a state-comparison bar chart SVG |
| `renderNav(nav)` | Generates prev/next navigation buttons + footer band |
| `page(c, sec, id)` | Assembles the complete HTML page |

## content.json Schema

Every article in `articles/NN/content.json` follows this schema.

### Top-level fields

```json
{
  "id": "NN",
  "section": "c0|c1|c2|c3|c4",
  "appendix": true,            // optional — forces appendix badge
  "titleMr": "मराठी शीर्षक",
  "titleEn": "English Title",
  "readingTime": "५",          // Devanagari digits
  "readingTimeEn": "5",
  "metaDesc": "...",           // optional, 160 chars; falls back to summary.mr
  "summary": { "mr": "...", "en": "..." },
  "body": [ /* array of blocks */ ],
  "nav": {
    "prev": { "id": "NN", "titleMr": "...", "titleEn": "..." },
    "next": { "id": "NN", "titleMr": "...", "titleEn": "..." }
  }
}
```

Omit `nav.prev` for the first article; omit `nav.next` for the last.

### Block types

#### `section` — content section
```json
{
  "type": "section",
  "headMr": "मराठी शीर्षक",
  "headEn": "English Heading",
  "paragraphs": [
    { "mr": "मराठी परिच्छेद.", "en": "English paragraph." }
  ],
  "insight": { "mr": "...", "en": "..." }   // optional, max 1 per article
}
```

#### `termBox` — Sanskrit term definition
```json
{
  "type": "termBox",
  "word": "संस्कृत शब्द",
  "roman": "IAST Transliteration",
  "defMr": "मराठी व्याख्या.",
  "defEn": "English definition."
}
```

#### `concepts` — key concepts card grid (2–4 items)
```json
{
  "type": "concepts",
  "items": [
    { "term": "शब्द", "roman": "Transliteration", "defMr": "...", "defEn": "..." }
  ]
}
```

#### `curiosity` — curiosity/जिज्ञासा box
```json
{ "type": "curiosity", "mr": "...", "en": "..." }
```

#### `activity` — reflective exercise list
```json
{
  "type": "activity",
  "mr": ["पहिली कृती.", "दुसरी कृती."],
  "en": ["First activity.", "Second activity."]
}
```

#### `infographic` — SVG diagram (see SVG types below)
```json
{
  "type": "infographic",
  "svgType": "flow|wheel|bars",
  "titleMr": "...", "titleEn": "...",
  "captionMr": "...", "captionEn": "...",
  // ...svgType-specific fields
}
```

#### `slides` — PDF slide viewer
```json
{
  "type": "slides",
  "titleMr": "सादरीकरण — स्लाइड्स",
  "titleEn": "Presentation Slides",
  "srcMr": "slides/slides-mr.pdf",
  "srcEn": "slides/slides-en.pdf"
}
```
The viewer auto-hides if the PDF file doesn't exist on the server. Always compress PDFs before committing (see PDF workflow below).

#### `phase2` — advanced reading teaser (always last in body)
```json
{ "type": "phase2", "mr": "...", "en": "..." }
```

### SVG Diagram Types

All SVGs are bilingual: two `<g data-lang="mr">` / `<g data-lang="en">` layers generated from JSON.

#### `flow` — left-to-right step diagram
```json

    "headMr": "उदाहरणे:", "headEn": "Examples:",
    "mr": ["उदाहरण १"], "en": ["Example 1"]

```

#### `wheel` — central concept + 4 quadrant panels
```json
{
  "svgType": "wheel",
  "center": { "mr": "केंद्र", "en": "Center", "roman": "...", "subMr": "...", "subEn": "..." },
```

## JavaScript Modules

### nav.js — IKS global object

`nav.js` exposes a global `IKS` object (IIFE pattern, no modules).

**State kept in module closure:**
- `lang` — current language (`'mr'` or `'en'`), persisted in `localStorage('iks-lang')`
- `fontSize` — current font size level (`'md'`/`'lg'`/`'xl'`), persisted in `localStorage('iks-fs')`
- `sidebarOpen` — boolean

**Public API:**

| Method | Description |
|--------|-------------|
| `IKS.setLang('mr'\|'en')` | Toggle display language; updates all `[data-lang]`, `[data-mr]`, `[data-en]` elements; saves to localStorage |
| `IKS.getLang()` | Returns current language string |
| `IKS.setFontSize('md'\|'lg'\|'xl')` | Sets `data-fs` attribute on `<html>`; CSS handles the scaling |
| `IKS.toggleSidebar()` | Opens/closes sidebar + overlay + hamburger |
| `IKS.closeSidebar()` | Closes sidebar (used by overlay click and Escape key) |
| `IKS.toggleSection(id)` | Toggles `.open` class on `#sec-{id}` in sidebar |
| `IKS.openSection(id)` | Adds `.open` class to a sidebar section |
| `IKS.setActiveArticle(num)` | Marks article link active; auto-opens its parent section |
| `IKS.init()` | Attaches hamburger click, overlay click, article link clicks, Escape key listener |

**Called twice per page load:** once on `DOMContentLoaded`, once after sidebar HTML is injected by `fetch()`.

**Language toggle mechanism:** `setLang()` iterates `[data-lang]` elements and sets `display:none` on those whose `data-lang` doesn't match. Also handles legacy `[data-mr]` / `[data-en]` attributes.

### slides.js — PDF slide viewer

Requires PDF.js (`cdnjs.cloudflare.com/libs/pdf.js/3.11.174`). Loaded only on pages that have a `slides` block.

**Entry point:** `IKS.initSlides()` — called from inline script after sidebar fetch (only if `hasSlides` flag is true).

**Architecture:**
- Per-viewer state stored in `_state` object keyed by viewer element ID
- In-flight load tracking in `_loading` to prevent race conditions
- `_loadViewer(viewer, lang)` — loads the PDF for the current language, hides viewer if no URL or file 404s
- `_renderPages(id)` — renders all pages as `<canvas>` elements at `baseScale × zoom`; sets track height to one page
- `baseScale` = track width / native PDF width — recomputed on every render to handle resize

**Zoom:** button steps of ±0.25; range 0.5×–3.0×; displayed as percentage

**Mobile pinch-zoom:** live CSS `transform: scale()` during pinch, re-render on `touchend`

**Desktop drag-scroll:** mousedown/move/up on `.slide-track`

**Extends `IKS` global with:**
- `IKS.initSlides()` — init all viewers
- `IKS.zoomSlides(btn, delta)` — zoom in/out
- `IKS.openSlidesPdf(btn)` — open current language PDF in new tab
- `IKS.switchSlideLang(btn, lang)` — switch language (also hooks into `IKS.setLang`)

**PDF worker URL:** `https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/pdf.worker.min.js`

### transitions.js — page-turn animations and swipe navigation

Runs immediately on load (IIFE). No exports needed — side-effect only.

**Features:**

1. **Entry animation (mobile only):** reads `sessionStorage('iks-nav-dir')` on load; adds `page-enter-right`/`page-enter-left`/`page-enter-home` class to `<main>`. CSS defines the keyframe animations.

2. **Shadow sweep overlay:** a `pt-shadow` div appended to `<body>` for duration of the transition, simulating paper catching light.

3. **Exit animation:** on nav-btn click (mobile), adds `page-exit-left`/`page-exit-right` class to `<main>`, navigates after 310ms.

4. **Desktop:** skips animations entirely — navigates immediately.

5. **Swipe gesture:** fires only when touch starts in outer 22% of screen width (`EDGE_ZONE = 0.22`). Requires ≥55px horizontal travel (`MIN_SWIPE`) with `|dx| > |dy| × 1.5` to reject vertical scrolling. Swipe left → next article; swipe right → prev article.

6. **Edge handle buttons:** thin translucent `‹` / `›` strips injected at left/right screen edges. Tap or swipe from there to navigate.

7. **Top nav row:** a `div.art-top-nav` inserted after `.art-header` showing prev/next article titles as buttons.

8. **Poster image hint:** a `button#infographic-hint` (◈ दृश्यात्मक विवरण) injected before the summary box; scrolls to the photo panel on click; removed if all poster images fail to load.

9. **Swipe hint banner:** `#swipe-hint` ("Swipe from edge to turn pages") shown once per session (tracked in `sessionStorage('iks-hint-shown')`); auto-dismisses after 3.2s or on first touch.

### sw.js — Service Worker (PWA)

Cache name: `iks-v1`

**Caching strategy:**
- **HTML pages** — Network first, fallback to cache, then 404.html
- **CSS / JS / images** — Cache first, fallback to network (cached on first fetch)
- **PDFs** — Network only (too large to cache; skipped entirely)
- **External CDN** — Network only (same-origin check)

**Pre-cached on install:** home page, 404, fonts.css, main.css, article.css, nav.js, slides.js, icons, sidebar.html, manifest.json.

### Fonts

### Article layout — art-photo-layout

On desktop, articles use a two-panel layout (class `art-photo-layout` on `<main>`):
- **Left panel** (`.art-photo-panel`): poster image with click-to-zoom. Hides itself via JS if both `adhyayNN-poster.jpg` and `adhyayNN-poster-en.jpg` fail to load (`onerror` → `_chkP()`).
- **Right panel** (`.art-scroll-panel`): article topbar + header + body + nav.

On mobile (≤860px): horizontal scroll layout — image panel is off-screen left; article starts scrolled to show text. Swipe panel hint shown.

## HTML Patterns

### Bilingual element pattern

Always emit both language variants. The `setLang()` function toggles visibility:
```html
<p data-lang="mr">मराठी मजकूर.</p>
<p data-lang="en" style="display:none;">English text.</p>
```

### Sidebar HTML (shared/sidebar.html)

Fetched via `fetch('/IKS/shared/sidebar.html')` on every page. Injected into `<nav class="sidebar" id="sidebar">`.

**Published article link:**
```html
<a class="sb-art-link done" href="/IKS/articles/NN/" data-art="NN">
  <span class="sb-art-num">NN</span>
  <span class="sb-art-titles">
    <span class="mr-t">मराठी शीर्षक</span>
    <span class="en-t">English Title</span>
  </span>
</a>
```
`done` class shows a checkmark. Remove `done` for draft articles.

**Section wrapper:**
```html
<div class="sb-section c0" id="sec-c0">
  <div class="sb-section-hdr" onclick="IKS.toggleSection('c0')">
    <div class="sb-badge">०</div>
    <div class="sb-section-label">
      <div class="mr">मध्यवर्ती संकल्पना</div>
      <div class="en">Central Concepts</div>
    </div>
    <span class="sb-arrow">▶</span>
  </div>
  <div class="sb-art-list"><!-- article links --></div>
</div>
```
First section (`c0`) has class `open` by default. Others are collapsed.

## PWA / Android App — TWA

The site is packaged as a **Trusted Web Activity (TWA)** Android app using [Bubblewrap CLI](https://github.com/GoogleChromeLabs/bubblewrap). The Android project lives directly in the repo root.

### Key files

| File | Purpose |
|------|---------|
| `twa-manifest.json` | Bubblewrap config — package ID, URLs, colors, shortcuts, signing key path |
| `build.gradle` | Root Gradle build (Android Gradle Plugin 8.9.1) |
| `app/build.gradle` | App module — reads `twaManifest` map, generates all `resValue` strings/colors/booleans |
| `app/src/main/AndroidManifest.xml` | Android manifest — activities, intent-filter for URL interception, notification service |
| `settings.gradle` | Gradle settings (includes `:app` module) |
| `gradle.properties` | Gradle JVM and project properties |
| `android.keystore` | Release signing keystore (alias: `android`) — **not committed to git** |
| `scripts/gen_pwa_assets.py` | Generates icon PNGs for all mipmap densities (requires Pillow) |

### App identity

| Field | Value |
|-------|-------|
| Package ID | `io.github.vivek_sovani.twa` |
| App name | `IKS&H` |
| Start URL | `https://vivek-sovani.github.io/IKS/` |
| Min SDK | 21 (Android 5.0 Lollipop) |
| Target SDK | 35 |
| Compile SDK | 36 |
| Orientation | Portrait only |
| Fallback | Custom Tabs (when TWA not supported) |

### Colors (splash / status bar)

| Element | Color |
|---------|-------|
| Theme / status bar | `#2D3E52` (dark blue-grey) |
| Dark theme status bar | `#000000` |
| Navigation bar | `#000000` |
| Splash background | `#2D3E52` |
| Splash fade-out | 300ms |

### App shortcuts (long-press icon)

Two shortcuts are defined in `twa-manifest.json` and `app/src/main/res/xml/shortcuts.xml`:
1. **आनंद — Article 01** → `https://vivek-sovani.github.io/IKS/articles/01/`
2. **ज्ञान — Article 03** → `https://vivek-sovani.github.io/IKS/articles/03/`

Shortcuts are auto-generated by a Gradle task (`generateShorcutsFile`) that runs before every build. To change shortcuts, edit `twaManifest.shortcuts` in `app/build.gradle` and also update `twa-manifest.json`.

### Key Android components

- **LauncherActivity** (`com.google.androidbrowserhelper.trusted`) — main entry point; opens the TWA; intercepts `https://vivek-sovani.github.io/IKS/*` intents via `android:autoVerify="true"` intent filter
- **DelegationService** — enabled when `enableNotifications: true`; handles push notification delegation from the browser
- **WebViewFallbackActivity** — fallback when Custom Tabs is unavailable
- **ManageDataLauncherActivity** — "Manage Space" in Android app settings
- **FileProvider** — authority `io.github.vivek_sovani.twa.fileprovider`; used for splash screen image

### Digital Asset Links (DAL)

For TWA URL interception to work (no browser chrome visible), the site must serve a Digital Asset Links file at:
```
https://vivek-sovani.github.io/.well-known/assetlinks.json
```
This links the site to the app's signing certificate fingerprint. If this file is missing or the fingerprint doesn't match, the app falls back to Custom Tabs (browser chrome visible). The `fingerprints` array in `twa-manifest.json` is currently empty — the DAL file must be set up separately.
